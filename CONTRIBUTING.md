# Contributing to ZC-CORE

Thank you for your interest in improving the ZC-CORE architecture and methodology.

## Normative Changes

Any proposed change to the normative requirements (e.g., test thresholds, invariant definitions, evidence matrix) must strictly adhere to the M1-M10 methodology invariants. 

Normative changes require:
1. A Technical Review phase.
2. A Normative Freeze.
3. A new minor or major version release according to the Governance framework.

**Frozen releases (such as v3.2.0) are immutable and cannot be patched with normative changes.**

## Typographical and Formatting Fixes

Non-normative changes (e.g., typo fixes, formatting, or illustrative diagram improvements) can be submitted as PRs but they must not alter the pass/fail constraints of the Conformance Test Specification.

Please ensure all PRs state whether they contain normative or non-normative changes.
