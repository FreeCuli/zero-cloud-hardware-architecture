# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| < 3.2.0 | :x:                |

## Reporting a Vulnerability

Please report security issues or protocol bypass vulnerabilities directly via the repository's security advisory tab or designated contact. Do not open public issues for zero-day exploits against the ZC-CORE methodology. We will evaluate the vulnerability against the M-Series methodology invariants and, if a bypass is confirmed, a CVE or methodology patch will be issued according to our governance framework.
